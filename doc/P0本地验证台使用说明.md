# P0 本地验证台使用说明

## 启动

先启动 P0 Docker 测试环境并确认 `.env.p0-test` 已初始化，然后在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-P0Console.ps1
```

控制台会监听 `127.0.0.1:18770` 并打开浏览器。关闭时在启动它的 PowerShell 窗口按 `Ctrl+C`。如端口冲突，可以使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\Start-P0Console.ps1 -Port 18771
```

控制台使用 Python 标准库，无须安装 Node.js、前端依赖或额外容器。网页服务绑定回环地址，并限制 Host / Origin；不要把它改成 `0.0.0.0` 监听。

## 页面能验证什么

- 容器、健康状态、端口绑定、测试域名解析、Higress → LiteLLM 模型目录和 Prometheus 抓取状态。
- 缺失/错误/当前/兼容 Key、错误 Host、Consumer Key 直连 LiteLLM、LiteLLM 无 Key 直连。
- 从 LiteLLM `/v1/models` 读取可用模型别名；默认选择 P0 基准 Qwen `my-qwen3.6-27b`。其他已配置别名可用于单项 Chat / SSE / Responses / 工具调用检查，但页面与服务端都会要求先确认真实调用风险；完整 P0 验收仍固定使用基准 Qwen。
- 最近 7 天最多 30 条 LiteLLM SpendLogs，展开单条可查看请求正文、响应正文、Token 与耗时；认证凭据字段显示为 `[REDACTED]`。
- 一键运行 `scripts/run_p0_acceptance.py --verify-rate-limit` 完整 P0 自动验收，覆盖 RPM / TPM、SpendLogs、凭证泄露检查、7 天日志留存、Envoy 指标、IP 策略及 Provider DNS 分类。
- 展示最近一次自动验收报告的安全摘要，并可打开原始 Markdown 报告。

除模型目录、认证与运行状态检查外，Chat / SSE / Responses / 工具调用都会实际访问当前选择的模型并产生 Token。非基准模型可能路由到不同 Provider 或产生实际费用，请只选获准测试的别名。完整验收不会受页面模型选择影响，仍调用基准 Qwen；TPM 测试会短暂使用 1 Token 测试阈值，脚本结束时恢复正常配置并清理 P0 专用 Redis 限流数据库。

## 用量与监控刷新
“用量与监控”按所选的最近 15 分钟、1 小时、24 小时或 7 天区间汇总 LiteLLM 本地 SpendLogs（请求数、成功/失败数、输入/输出/总 Token、按模型统计），并复用 Higress / Prometheus 原生指标（网关请求数、状态码和平均延迟）。LiteLLM 模型请求数与 Higress 网关请求数口径不同：后者还会包含未进入模型服务的认证拒绝等网关流量。该摘要每 15 秒刷新一次，与 `config/monitoring/prometheus.yml` 的抓取间隔一致；LiteLLM 数据在请求完成并写入 SpendLogs 后才会计入。Spend 金额保持 UNKNOWN，不作为预算或财务结算依据。容器健康等运行状态仍需手动点击“刷新状态”；最近调用日志也仍可手动刷新。最近验收状态单独显示，不再混入所选时间段的用量统计。

## 密钥和日志

当前 Consumer Key 与兼容期 Key 从 Git 忽略的 `.env.p0-test` 由本机 Python 服务端读取，不在页面显示，也不会写入服务访问日志。客户端请求记录依 P0 既定策略进入本机 LiteLLM SpendLogs；页面本身不会保存凭证。错误响应在显示前会对本地已知密钥做脱敏。

“最近调用日志”只读查询 P0 专用 PostgreSQL 中 7 天内的记录，默认折叠正文，点击一行后再显示请求/响应 JSON。数据库中的 `api_key` 列不向页面返回；正文里的 Authorization、API Key、Token、Secret、Password 等凭据字段会屏蔽。日志内容仍可能包含用户 Prompt 或模型输出，所以页面只监听 `127.0.0.1`，仅供本机测试人员查看。

页面不提供 Key 轮换、配置回滚、生产部署或 IP 白名单启用操作。这些操作需要运维决策或专门的变更流程，不是日常功能探测。

## 状态边界

- Qwen 单价未知：LiteLLM Spend 不作为费用估算或财务结算。
- IP 限制保持未应用：等待批准的具体 CIDR。
- Provider DNS 地址本身不能证明网络属于内网/专线。
- Higress AI Statistics 不作为本地 P0 验收来源。
- 本地验证通过不等于服务器预发布或生产验收通过。

决策细节见 [P0 上线前决策清单](P0上线前决策清单-2026-09-22.md)，自动验收仍以 [Run-P0EndToEnd.ps1](../scripts/Run-P0EndToEnd.ps1) / `scripts/run_p0_acceptance.py` 生成的报告为准。
